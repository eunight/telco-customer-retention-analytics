# Telco Customer Retention Analytics

## Descripción del Proyecto
Ecosistema de modelos predictivos diseñado para anticipar la fuga de clientes (churn), estimar el valor de vida (LTV) y optimizar estrategias de venta cruzada en el sector de telecomunicaciones mediante Minería de Datos.

## Stack Metodológico
* **Clasificación Supervisada:** Regresión Logística, Árboles de Decisión (Predicción de Churn).
* **Regresión:** Regresión Lineal Múltiple, Support Vector Regression (Predicción de Ingresos).
* **Clasificación No Supervisada:** K-Medias (Segmentación de perfiles).
* **Asociación:** Algoritmo Apriori (Análisis transaccional de servicios).
